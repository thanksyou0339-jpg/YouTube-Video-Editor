# Islamic Video Maker

A simple web-based Islamic video generator.

## Features

- Arabic Hadith
- Urdu Translation
- Explanation
- AI Voice
- Background Image
- Automatic MP4 generation
- Video Preview
- MP4 Download
- Browser video recording
